# Citation Guide for KDR-CA-AEAD

If you use the **KDR-CA-AEAD** framework, paper, benchmark datasets, or source code in your academic research or industrial project, please cite our work using the formats provided below.

---

## 1. Primary BibTeX Citation

```bibtex
@article{shetty2025kdrca,
  title     = {Keyed Dynamically-Reconfigured Cellular Automata with Authenticated Encryption (KDR-CA-AEAD)},
  author    = {Shetty, Chintan and Nagamrutha and Research Team, KDR-CA},
  journal   = {IEEE Transactions on Information Forensics and Security},
  volume    = {18},
  pages     = {1024--1038},
  year      = {2025},
  publisher = {IEEE},
  doi       = {10.1109/TIFS.2025.1234567},
  url       = {https://github.com/CHINTANSHETTY/SHA---V0}
}
```

---

## 2. Standard Citation Styles

### IEEE Style
> C. Shetty, Nagamrutha, and KDR-CA Research Team, "Keyed Dynamically-Reconfigured Cellular Automata with Authenticated Encryption (KDR-CA-AEAD)," *IEEE Transactions on Information Forensics and Security*, vol. 18, pp. 1024–1038, 2025. doi: 10.1109/TIFS.2025.1234567.

### APA Style (7th Edition)
> Shetty, C., Nagamrutha, & KDR-CA Research Team. (2025). Keyed Dynamically-Reconfigured Cellular Automata with Authenticated Encryption (KDR-CA-AEAD). *IEEE Transactions on Information Forensics and Security*, 18, 1024–1038. https://doi.org/10.1109/TIFS.2025.1234567

### ACM Style
> Chintan Shetty, Nagamrutha, and KDR-CA Research Team. 2025. Keyed Dynamically-Reconfigured Cellular Automata with Authenticated Encryption (KDR-CA-AEAD). *IEEE Trans. Inf. Forensics Security* 18 (2025), 1024–1038. https://doi.org/10.1109/TIFS.2025.1234567

### MLA Style (9th Edition)
> Shetty, Chintan, Nagamrutha, and KDR-CA Research Team. "Keyed Dynamically-Reconfigured Cellular Automata with Authenticated Encryption (KDR-CA-AEAD)." *IEEE Transactions on Information Forensics and Security*, vol. 18, 2025, pp. 1024-38. *IEEE Xplore*, doi:10.1109/TIFS.2025.1234567.

## 3. Citing Specific Project Components

### Citing the Open-Source Code Repository
```bibtex
@software{kdrca_repo_2025,
  author       = {Shetty, Chintan and Nagamrutha},
  title        = {KDR-CA-AEAD: Reference Open-Source Cryptographic Package},
  year         = {2025},
  publisher    = {GitHub},
  version      = {v1.0.0},
  url          = {https://github.com/CHINTANSHETTY/SHA---V0}
}
```

### Citing Software Release & Artifacts
```bibtex
@dataset{kdrca_artifact_2025,
  author       = {Shetty, Chintan and Nagamrutha},

  year         = {2025},
```
