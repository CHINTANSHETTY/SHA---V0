## 4. Zenodo Archival & Indexing Workflow

Upon publishing an official release tag (e.g., `v1.0.0`), maintainers can integrate with Zenodo via GitHub repository webhooks:

1. Maintainer tags and pushes release tag (`git tag v1.0.0 && git push origin v1.0.0`).
2. Zenodo pulls the source zip archive, computes SHA-256 checksums, and mints a persistent digital object identifier (DOI).
3. The assigned DOI is updated in `CITATION.cff` and `codemeta.json`.
