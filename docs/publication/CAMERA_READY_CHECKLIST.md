# Camera-Ready Submission Checklist

This document details the final verification checklist required prior to uploading the camera-ready version of the **KDR-CA-AEAD** paper to the publisher portal.

---

## 1. Final Proofreading Verification
- [ ] Checked for typographical errors, double spaces, and missing punctuation.
- [ ] Confirmed consistency in variable names ($K_r$, $K_c$, $K_a$, $S_{salt}$, $N_{nonce}$) across text, equations, and algorithms.
- [ ] Verified capitalization in section headings according to publisher standards.

## 2. Reference Verification & Completeness
- [ ] All references cited in the body text appear in the bibliography list, and vice versa.
- [ ] Checked all author names, journal titles, volume/issue numbers, page ranges, and publication years.
- [ ] Added DOIs (`https://doi.org/...`) to all reference entries where available.

## 3. Figure Numbering & Quality Check
- [ ] Figures numbered sequentially from Figure 1 to the final figure.
- [ ] All figure captions placed *below* the figure.
- [ ] Resolution verified at 300+ DPI for bitmap formats; vector formats checked for rendering artifacts.

## 4. Equation Numbering & Alignment
- [ ] Equations numbered sequentially in right-aligned parentheses `(1)`, `(2)`.
- [ ] Inline mathematics correctly formatted without line-breaking awkwardness.

## 5. Table Formatting & Caption Placement
- [ ] Table captions placed *above* the table (standard IEEE rule).
- [ ] Column headers formatted clearly with appropriate measurement units.

## 6. ORCID & Author Affiliation Verification
- [ ] Author affiliations, department, university/institution, city, state, country, and email addresses verified.
- [ ] Active ORCID iD badges/links attached to each author name.

## 7. Metadata Verification
- [ ] PDF document properties (Title, Author, Subject, Keywords) updated in LaTeX file (`\hypersetup`).
- [ ] Watermarks, draft banners, and page numbers removed (if publisher manages page numbering).

## 8. Final PDF Validation
- [ ] Passed IEEE PDF eXpress / ACM PDF Checker validation.
- [ ] Confirmed font embedding status (`pdffonts camera_ready.pdf`).
- [ ] Verified physical layout and page count fits venue requirements.
