\section{Literature Review \& Background}
\label{sec:literature_review}

\subsection{Healthcare Data Security}
\label{subsec:healthcare_sec}
The confidentiality of electronic health record (EHR) telemetry and clinical diagnostic data is paramount when transmitting records across distributed networks. Patient records contain sensitive attributes including patient identifiers, clinical diagnoses, treatment regimens, and vital sign measurements. Beyond confidentiality, healthcare security frameworks require exact, loss-less data recoverability to ensure that decrypted clinical text strings match the original record without bit corruption.

\subsection{Conventional Symmetric Cryptography}
\label{subsec:conventional_crypto}
Established symmetric ciphers provide baseline confidentiality for electronic data. The Advanced Encryption Standard (AES) \cite{daemen2002design, dworkin2007recommendation} is a widely adopted block cipher operating on 128-bit state blocks using substitution-permutation networks (SPN). Similarly, ARX-based stream ciphers such as ChaCha20 \cite{bernstein2008chacha, rfc8439} rely on 32-bit addition, rotation, and XOR operations. In addition, generic compositions such as Encrypt-then-MAC (EtM) \cite{bellare2000authenticated} and Authenticated Encryption with Associated Data (AEAD) frameworks \cite{rogaway2002authenticated} combine confidentiality primitives with message authentication codes to protect unencrypted header metadata against ciphertext tampering. While these standard ciphers serve as mature benchmarks, researchers continue to explore alternative block transformation models that utilize simple bitwise cellular operations.

\subsection{Cellular Automata in Cryptography}
\label{subsec:ca_background}
Cellular Automata (CA), formalized by von Neumann and Wolfram \cite{wolfram1983statistical}, consist of discrete arrays of cells that evolve synchronously according to local transition rules. A 1D Elementary Cellular Automaton (ECA) updates cell states $s_i^{t+1} = f(s_{i-1}^t, s_i^t, s_{i+1}^t)$ based on an 8-bit Wolfram rule integer \cite{wolfram1986random}. Although rules such as Rule 30 were initially investigated for pseudo-random keystream generation, static-rule 1D CA generators exhibited vulnerabilities under linear and differential cryptanalysis \cite{gutowitz1993cryptology, nandi2002theory, biham1991differential, matsui1993linear}.

\subsection{Reversible and Block Cellular Automata}
\label{subsec:reversible_ca}
To ensure complete data recoverability in encryption, Cellular Automata must exhibit bijective, loss-less state transitions. Margolus neighborhood Cellular Automata operate on non-overlapping $2 \times 2$ cell blocks rather than individual cell sites. By applying a 4-bit bijective local rule over $2 \times 2$ state matrices and alternating between standard and shifted spatial partitions, Margolus CA architectures guarantee structural reversibility. Inverting the local rule mapping and reversing partition steps guarantees exact mathematical recovery of the input matrix state.

\subsection{Hash Functions and SHA-512 Key Derivation}
\label{subsec:sha512_kdf}
Cryptographic hash functions process arbitrary-length binary inputs into fixed-length digest outputs. Key Derivation Functions (KDFs), such as HKDF \cite{rfc5869, nist2020sp80056c}, extract pseudo-random keys from input keying material using HMAC constructions. In the proposed cryptosystem, key derivation is performed directly using the SHA-512 hash algorithm: a 256-bit binary key ($K_{256}$) is formed by extracting the first 32 bytes (256 bits) of the SHA-512 digest computed over the user's password string.

\subsection{Research Gap}
\label{subsec:research_gap}
While existing literature explores various 1D and multi-dimensional CA stream and block models, prior work primarily focuses on unshifted or static rule topologies. A research gap exists in evaluating a unified, reversible 256-bit block cryptosystem that integrates:
\begin{enumerate}
    \item 256-bit block partitioning mapped to $16 \times 16$ binary matrices;
    \item Bijective $2 \times 2$ Margolus CA local transformations with alternating standard and shifted periodic partitions;
    \item Inter-round 2D circular matrix shifts;
    \item SHA-512-derived $K_{256}$ key mixing; and
    \item Empirical round-scaling evaluations across $R \in \{2, 4, 6, 8, 10\}$ measuring bit diffusion, Byte NPCR, Byte UACI, latency, and exact healthcare record recovery.
\end{enumerate}
