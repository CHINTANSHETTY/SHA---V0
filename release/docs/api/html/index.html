Module: crypto.ca.engine

Deterministic One-Dimensional Elementary Cellular Automata Evolution Engine. This module implements deterministic 1D Cellular Automata evolution supporting arbitrary binary state lengths, configurable boundary conditions ("periodic" and "null"), and multi-generation step evolution. Boundary Conditions: - Periodic ("periodic"): Wraps around both ends of the cell array. Left neighbor of cell 0 is cell N-1. Right neighbor of cell N-1 is cell 0. For a 1-cell array, left, center, and right neighbors are all cell 0. - Null ("null"): Boundary conditions outside the cell array are treated as 0 (zero-padded). Left neighbor of cell 0 is 0. Right neighbor of cell N-1 is 0. Determinism & Security: Evolution is strictly deterministic. Given identical inputs (state, rule, generations, and boundary), the evolution output is guaranteed to be identical. No randomness is used. Time Complexity: - evolve_step: O(N) where N is the length of the binary state array. - evolve: O(N * generations) where N is state length.

Public Functions

  • evolve(state: Union[List[int], Tuple[int, ...], str], rule: Any, generations: Any = 1, boundary: Any = 'periodic') -> List[int]: Perform deterministic one-dimensional cellular automata evolution across multiple generations.
  • evolve_step(state: Union[List[int], Tuple[int, ...], str], lookup: Union[mappingproxy, Dict[Tuple[int, int, int], int]], boundary: str = 'periodic') -> List[int]: Perform a single generation evolution step for a 1D Cellular Automaton state.
  • validate_boundary(boundary: Any) -> str: Validate and normalize a boundary condition string.
  • validate_generations(generations: Any) -> int: Validate that generations count is a positive integer (>= 1).
  • validate_state(state: Any) -> List[int]: Validate and normalize a binary state input.

Module: crypto.ca.mapping

Dynamic Rule Mapping and Configuration Subsystem for KDR-CA-AEAD. This module manages Cellular Automata rule selection, indexing lookups, bijective rule transformations, sequence rotation/cycling, configuration load/export, and JSON serialization. Determinism & Security: - All mapping and sequence operations are strictly deterministic and pure. - Configuration schema versioning ("version": 1) is enforced on serialization. - Bijective mappings enforce unique target rules to ensure deterministic inversions. Time Complexity: - validate_rule_sequence: O(N) where N is sequence length. - build_rule_lookup: O(N). - get_rule: O(1). - map_rules & invert_rule_mapping: O(N). - serialize_rule_sequence & deserialize_rule_sequence: O(N).

Module: crypto.ca.rules

Elementary Cellular Automata (ECA) Rule Engine Representation and Utilities. This module implements support for all 256 Wolfram Elementary Cellular Automata rules (Rules 0 to 255). It provides rule validation, deterministic 8-bit lookup table conversion, immutable cached lookup tables, and neighborhood evaluation utilities. Wolfram Rule Representation: An Elementary Cellular Automaton consists of a 1D grid of binary cells. The next state of a cell depends on its current state and its left and right neighbors. There are 2^3 = 8 possible 3-cell neighborhood configurations (111 down to 000). Neighborhood to Bit Mapping: Neighborhood (L, C, R) Binary Value Bit Position in Rule ---------------------------------------------------------- 111 (1, 1, 1) 7 Bit 7 110 (1, 1, 0) 6 Bit 6 101 (1, 0, 1) 5 Bit 5 100 (1, 0, 0) 4 Bit 4 011 (0, 1, 1) 3 Bit 3 010 (0, 1, 0) 2 Bit 2 001 (0, 0, 1) 1 Bit 1 000 (0, 0, 0) 0 Bit 0 Time Complexity: - parse_rule: O(1) time complexity (memoized up to 256 entries). - validate_rule: O(1) time complexity. - get_neighborhood_output: O(1) time complexity.

Public Functions

  • get_neighborhood_output(rule: Any, left: Any, center: Any, right: Any) -> int: Evaluate a single 3-cell neighborhood for a given Wolfram rule.
  • parse_rule(rule: Any) -> mappingproxy: Parse and convert an integer rule into an immutable binary lookup table.
  • rule_to_binary(rule: Any) -> str: Convert an integer rule (0-255) into its 8-bit binary string representation.
  • validate_rule(rule: Any) -> int: Validate that the given rule is an integer within the range [0, 255].

Module: crypto.ca.utils

Cellular Automata Utility Module. This module provides deterministic helper functions for binary state conversions, state initialization, random state generation, state validation, distance and population metrics, matrix manipulations, and state slicing operations used across the KDR-CA-AEAD cryptographic engine. Determinism & Security: - Random state generation uses an isolated `random.Random(seed)` instance to ensure 100% reproducible states without modifying Python's global `random` state. - All conversion and metric functions behave deterministically. Time Complexity: - State Conversions & Slicing: O(N) where N is the length of the binary state. - Metrics (Population count, Hamming distance, XOR, Inversion): O(N). - Matrix conversions: O(M * N) where M is generations and N is state width. - Integer conversions: O(width).

Public Functions

  • chunk_state(state: Union[Sequence[int], str], size: Any) -> List[List[int]]: Split a binary state into fixed-size chunk sub-states.
  • compare_states(a: Any, b: Any) -> bool: Compare two binary states for equality.
  • copy_state(state: Union[Sequence[int], str]) -> List[int]: Return a deep copy of a binary state array.
  • flatten_states(states: Any) -> List[int]: Flatten a sequence of nested binary states into a single 1D state array.
  • hamming_distance(state1: Union[Sequence[int], str], state2: Union[Sequence[int], str]) -> int: Calculate the Hamming distance (number of differing positions) between two equal-length states.
  • int_to_state(value: Any, width: Any) -> List[int]: Convert a non-negative integer into a big-endian binary state array of specified width.
  • invert_state(state: Union[Sequence[int], str]) -> List[int]: Bitwise invert a binary state (0 -> 1, 1 -> 0).
  • matrix_to_states(matrix: Any) -> List[List[int]]: Validate and convert a 2D matrix representation back into a list of state rows.
  • one_state(length: Any) -> List[int]: Generate an all-one binary state array of specified length.
  • pad_state(state: Union[Sequence[int], str], length: Any, value: Any = 0) -> List[int]: Pad a binary state to target length using specified bit value.
  • population_count(state: Union[Sequence[int], str]) -> int: Count the number of set bits (ones) in a binary state.
  • random_state(length: Any, seed: Optional[Any] = None) -> List[int]: Generate a pseudo-random binary state array.
  • state_from_string(bits: str) -> List[int]: Convert a binary string (e.g. "010101") into a List[int] state.
  • state_to_int(state: Union[Sequence[int], str]) -> int: Convert a big-endian binary state array back into an integer.
  • state_to_string(state: Union[Sequence[int], str]) -> str: Convert a binary state sequence into a string representation (e.g. [1,0,1] -> "101").
  • states_to_matrix(states: Any) -> List[List[int]]: Convert a sequence of generation states into a 2D matrix (List[List[int]]).
  • trim_state(state: Union[Sequence[int], str], length: Any) -> List[int]: Trim a binary state to a shorter target length.
  • validate_bit(bit: Any) -> int: Validate that a value is a binary bit integer (0 or 1).
  • validate_state_length(length: Any) -> int: Validate that a state length parameter is an integer >= 1.
  • validate_width(width: Any) -> int: Validate that a bit width parameter is an integer >= 1.
  • xor_states(a: Union[Sequence[int], str], b: Union[Sequence[int], str]) -> List[int]: Perform bitwise XOR between two equal-length binary states.
  • zero_state(length: Any) -> List[int]: Generate an all-zero binary state array of specified length.
