# Development Setup Guide

```bash
# Clone
git clone https://github.com/CHINTANSHETTY/SHA---V0.git
cd SHA---V0

# Virtual Environment
python -m venv venv
source venv/bin/activate  # Or venv\Scripts\activate on Windows

# Install Dependencies
pip install -r requirements.txt

# Run Tests
$env:PYTHONPATH="."
python -m pytest
```
