# Getting Support for KDR-CA-AEAD

**Framework:** Keyed Dynamically-Reconfigured Cellular Automata with Authenticated Encryption (KDR-CA-AEAD v1.0.0)  

Thank you for using **KDR-CA-AEAD**! We offer several channels for getting support, asking technical questions, reporting bugs, and discussing cryptographic research.

---

## 1. How to Ask Questions

If you have general questions about installing, integrating, or understanding the cryptographic design of KDR-CA-AEAD:

1. **Check the Documentation First**:
   - [User Guide](docs/user_guide.md) – Overview of installation, CLI usage, and quickstart examples.
   - [Developer Guide](docs/developer_guide.md) – Setup instructions for contributors and test execution.
   - [API Reference](docs/api_reference.md) – Detailed class and function signatures.
   - [Security Guide](docs/security_guide.md) – Formal threat model and cryptographic bounds.
   - [Troubleshooting Guide](docs/troubleshooting.md) – Common installation and execution issues.

2. **Use GitHub Issues / Discussions**:
   - Use GitHub Issues for technical questions until GitHub Discussions are fully enabled for this repository.
   - When asking questions via Issues, please apply the `documentation` or `question` label.

---

## 2. How to Report Bugs

If you encounter a software bug, build failure, or incorrect behavior:

1. Search open and closed [GitHub Issues](https://github.com/CHINTANSHETTY/SHA---V0/issues) to verify the bug has not already been reported.
2. Use our standardized **[Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md)**.
3. Provide:
   - Python version and OS platform.
   - Minimal code snippet or CLI command to reproduce the issue.
   - Complete stack trace or output logs.
   - Expected vs. actual behavior.

---
