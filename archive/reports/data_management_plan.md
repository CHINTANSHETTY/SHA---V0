# Data Management Plan (DMP) — KDR-CA-AEAD v1.0.0

## Data Storage & Formats
- **Authoritative Master Formats**: Vector SVG (`.svg`), JSON schemas (`.json`), YAML config (`.yaml`), LaTeX source (`.tex`).
- **Compiled Vector & Raster Outputs**: Vector PDF (`.pdf`), 300 DPI PNG (`.png`), Tabular CSV (`.csv`).
- **Retention & Backup Strategy**: Permanent archival on GitHub and Zenodo with dual SHA-256 and SHA-512 checksum tracking.
