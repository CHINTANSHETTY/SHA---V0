# KDR-CA-AEAD Archival & Long-Term Preservation Package

This directory contains the FAIR-compliant metadata, DOI packaging guides, Software Heritage archival instructions, citation packages, data management plans, and checksum inventories for Phase 3.2.7.

## Directory Layout
- `metadata/`: `fair_metadata.json`, `environment_snapshot.json`
- `manifests/`: `archive_manifest.json`, `ARCHIVE_MANIFEST.md`
- `citations/`: `CITATION.cff`, `citation.bib`, `citation.txt`
- `reports/`: `artifact_inventory.md`, `doi_package.md`, `software_heritage.md`, `reproducibility_checklist.md`, `data_management_plan.md`
- `checksums/`: `dual_hash_checksums.sha256`
- `certification.md`: Preservation certificate and reproducibility badge
