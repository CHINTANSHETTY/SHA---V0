# DOI Package & Repository Archival Checklist (Zenodo / Figshare / OSF)

This guide details the preparation for assigning a Digital Object Identifier (DOI) to the **KDR-CA-AEAD** research artifact.

## Recommended Repositories
1. **Zenodo (CERN / OpenAIRE)**: Recommended for GitHub repository integration and automatic DOI generation.
2. **Figshare**: Alternative platform for publishing research datasets, vector graphics, and manuscript PDFs.
3. **Open Science Framework (OSF)**: Alternative project management and archival repository.

## Upload & DOI Reservation Checklist
- [x] `release/kdr-ca-aead-v1.0.0.zip` ready for upload.
- [x] `CITATION.cff` validated for automated metadata parsing.
- [x] `archive/fair_metadata.json` populated with keywords and author details.
- [x] `paper/final.pdf` manuscript included.
